Импорт CSV — резервный способ

Основной источник данных — Instagram API (страница «API»). CSV нужен, пока API не подключён, для данных, которых нет в API (B2B-заявки, удержание из приложения), и для конкурентов, недоступных через Business Discovery. Ручной импорт не перезаписывает значения, полученные из API, — только заполняет пустые поля.

Пустая ячейка = «нет данных». Примеры файлов — в папке samples/.
