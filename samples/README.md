# Примеры файлов импорта

Значения в этих файлах **вымышленные** и служат только для демонстрации формата.
`example_competitor` — несуществующий аккаунт; реальным конкурентам цифры не приписываются.

- Пустая ячейка = «нет данных» (не ноль).
- Разделитель — запятая, точка с запятой или табуляция; кодировка UTF-8 или Windows-1251.
- Даты: `YYYY-MM-DD`, `YYYY-MM-DD HH:MM`, `DD.MM.YYYY` или ISO 8601.
- Числа вида `12,5K` / `1.2М` распознаются.
