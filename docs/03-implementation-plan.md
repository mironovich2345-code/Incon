### Ваши действия на этапе 1
1. Запустить приложение (README), указать свой username и текущие 208 подписчиков.
2. Ежедневно записывать снимок подписчиков (кнопка на «Обзоре») — это база для прироста.
3. Сгенерировать контент-план от даты старта серии.
4. После публикаций заносить метрики из приложения Instagram (Статистика ролика) в CSV или
   экспорт Meta Business Suite, импортировать, связывать ролик со слотом плана.
5. Заявки из директа/CRM вносить вручную в колонку «заявки».
6. Для конкурентов — вручную внести публично видимые просмотры/лайки/комментарии (CSV) до подключения API.

## Этап 2 — подключение API (требует вашего подтверждения)
1. **Вы** создаёте Meta-приложение по [04-meta-app-setup.md](04-meta-app-setup.md) и заполняете `.env`.
2. `META_API_ENABLED=true`, перезапуск, «API» → «Войти через Meta».
3. Первая синхронизация: страница «Метрики» покажет, какие метрики Meta реально вернула.
4. Проверить статус Business Discovery для каждого конкурента.
5. Настроить ежедневный запуск синхронизации (cron / systemd timer → `POST /meta/sync`),
   чтобы копить историю публичных метрик конкурентов и снимки подписчиков.
6. Дневные insights аккаунта (`follows_and_unfollows`, `reach`, `views`) — добавить в синхронизацию
   после проверки формата ответа на вашем аккаунте (клиент `account_insights` уже есть).

## Этап 3 — усиление анализа
- Классификация хуков/форматов через Claude по транскриптам своих роликов (вместо правил).

- Автоматический ежедневный отчёт после синхронизации.
- Сравнение «план vs факт» по каждой ячейке эксперимента с доверительными интервалами (bootstrap).
