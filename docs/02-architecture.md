## Принципы данных
- **NULL = нет данных.** Пустая ячейка CSV или метрика, которую не вернул API, хранится как NULL и
  отображается «—». Производные показатели (подписки на 1000 просмотров, досмотр) не считаются,
  если нет хотя бы одного исходного значения.
- **n рядом с каждой медианой.** Видно, на скольких роликах основан вывод; группы < 5 роликов
  выделяются серым.
- **Источник у каждой записи:** `metrics_source` (manual / api / business_discovery),
  `classification_source` (rules / manual / claude).
- **Повторный импорт не затирает известные значения** пустыми.
- **Каталог метрик** (`app/metrics.py`) — единый справочник: статус по документации + результат
  реальной проверки API (`metric_availability`).

## Выбросы у конкурентов
- Медиана просмотров по публикациям аккаунта; ролик — выброс, если `views ≥ OUTLIER_RATIO × медиана`
  (по умолчанию ×2). Дополнительно — robust z-score по MAD.
- Если просмотров нет ни у одной публикации, база — «лайки + комментарии», и это явно подписано.
- Общий рейтинг сравнивает кратность к медиане своего аккаунта, поэтому ролики аккаунтов разного
  размера сопоставимы.
- «Lift» паттернов: во сколько раз формат/тема/хук чаще встречаются среди выбросов, чем в среднем.

## Эксперимент 25 Reels / 5 дней
Три взаимно ортогональных латинских квадрата 5×5: формат = (день + слот) mod 5,
тема = (2·день + слот) mod 5, хук = (3·день + слот) mod 5. Каждый формат, тема и хук — по разу в
каждый день и в каждом слоте времени; каждая пара характеристик встречается ровно один раз.
Это позволяет сравнивать их без смешения друг с другом и со временем публикации.
При ~200 подписчиках шум высокий — результаты серии трактуются как гипотезы для следующей.

## Безопасность
- Пароль Instagram не запрашивается; вход только через OAuth-диалог Meta.
- Токены зашифрованы (Fernet), ключ — в `TOKEN_ENCRYPTION_KEY` на сервере; в UI видны только метаданные.
- OAuth `state` проверяется (CSRF), TTL 10 минут.
- Интерфейс по умолчанию слушает `127.0.0.1`; при доступе извне обязателен `APP_PASSWORD` + HTTPS.
- Раздача кадров защищена от path traversal.
- Публикация не реализована ни в клиенте Meta, ни в workflow; scope `instagram_content_publish` не запрашивается.

## Claude
- Модель задаётся `ANTHROPIC_MODEL` (по умолчанию `claude-opus-5-5`), адаптивное мышление, стриминг,
  серверный фолбэк при отказе.
- Без ключа функции возвращают готовый промпт — его можно выполнить в Claude вручную или передать
  Claude Code; ответ вставляется в интерфейс.
- Системный промпт запрещает выдумывать метрики и копировать содержание чужих роликов: из референсов
  переносятся только приёмы и структура.
